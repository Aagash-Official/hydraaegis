Hydra Aegis

An AI-powered platform for detecting threats across files and network traffic.

Two connected tools, one goal: catch what signature-based security misses.

What we built

Hydra Aegis combines two detection tools into a single workflow. The first tool analyses files to classify malware and flag suspicious behaviour, including threats that don't match any known signature. The second tool watches network traffic to spot command-and-control activity, using anomaly detection to catch techniques that try to blend in with normal traffic.

The tools

Tool 1

Malware Classifier

Analyses executable files and scripts to identify malware families and behaviour patterns, including fileless and packed threats that traditional scanners often miss.

Tool 2

Network Threat Detection

Monitors network traffic for signs of command-and-control activity. Built to catch anomalies even when attackers try to evade detection, with explainable results at every step.
