What we built

Hydra Aegis combines two detection tools into a single workflow. The first tool analyses files to classify malware and flag suspicious behaviour, including threats that don't match any known signature. The second tool watches network traffic to spot command-and-control activity, using anomaly detection to catch techniques that try to blend in with normal traffic.

Detection layers
Layer 1

PE Category Classifier

XGBoost (200 trees) trained on 42 features — 27 static PE header features and 15 dynamic behavioral features. Classifies into Benign, Ransomware, RAT, Stealer, or Trojan.

Layer 2

Family Classifier

Identifies the specific malware family — LockBit, NanoCore, Emotet, and 23 others — once a category is established. 94.3% accuracy across 26 families.

Layer 3

Fileless / PowerShell Detector

Separate Random Forest trained on 26 text features from raw PowerShell script content — no execution required. Catches obfuscation, memory injection, persistence, and C2 download patterns.

Layer 4

Real .exe Scanning + Entropy + UPX

Upload any .exe, .dll, or .zip. Shannon entropy per PE section detects packing. UPX section name fingerprinting (UPX0/UPX1) gives definitive packing confirmation independent of the ML classifier.

Layer 5

Adversarial Mimicry Attack

A white-box mimicry attack simulating a real attacker who reads the feature set and manipulates packing ratio values. Both XGBoost and RF are hardened via adversarial retraining to near-zero evasion.

Layer 6

SHAP Explainability

Model-aware SHAP: TreeExplainer for XGBoost/RF, LinearExplainer for LR/SVM. Every prediction shows a waterfall chart of the top-10 features — green pushes toward the predicted class, red pushes away.

Layer 7

Gemini AI Analyst Reports

Gemini 2.5 Flash generates a four-section report — Threat Assessment, Key Indicators, Investigate Next, Risk Level — from SHAP values and prediction confidence. Works across all model types.

Layer 8

VirusTotal Integration

Hash-based lookup — no file upload to VT. Retrieves the threat label and engine count, then estimates behavioral features from the threat category to improve classifier accuracy on real malware.

Adversarial robustness — mimicry attack results

Both models were stress-tested under a feature-space mimicry attack. XGBoost is more accurate but more vulnerable under attack — both harden to near-zero evasion after adversarial retraining.
